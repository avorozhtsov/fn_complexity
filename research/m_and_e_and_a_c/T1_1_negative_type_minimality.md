## 1. Setup

A signature is a decreasing tuple of positive integers, `Z_a(β) = Σ_i a_i^β`, and

```
C(g → f) = inf_{β ∈ [0,∞]} log Z_g(β) / log Z_f(β),      C(g→f)|_{β=∞} = log max g / log max f,
d(a,b)   = − log ( C(a→b) · C(b→a) ) ≥ 0.
```

Writing `u_a(β) = log log Z_a(β)` one has `−log C(g→f) = sup_β (u_f − u_g)`, hence

```
d(a,b) = osc_β ( u_a − u_b )  =  max_β (u_a−u_b) − min_β (u_a−u_b).
```

So the exchange metric is a **Chebyshev (sup-norm modulo constants) metric on the
log-log partition profiles** `u_a : [0,∞] → ℝ`. Everything below is geometry of
that picture. The identity is also what makes the search fast: one matrix of
`u`-values on a β-grid gives all pairwise distances by row differences.

Recall the Deza–Laurent cones (`Geometry of Cuts and Metrics`):

```
CUT_n (ℓ₁)  ⊆  HYP_n (hypermetric)  ⊆  NEG_n (negative type)  ⊆  MET_n (metric)
```

with `d ∈ NEG_n ⟺ xᵀDx ≤ 0 for all x with Σx = 0`, and the hypermetric
inequalities `Σ_{i<j} b_i b_j d_ij ≤ 0` for integer `b` with `Σ b = 1`
(`b = (1,1,−1)` is the triangle inequality, `b = (1,1,1,−1,−1)` the pentagonal one).

## 2. The minimum is exactly five

### 2.1 Lower bound: four points can never fail (proved)

*Every cut semimetric is of negative type.* For `S ⊆ {1,…,n}` let
`δ_S(i,j) = 1` if `|{i,j} ∩ S| = 1` and `0` otherwise. If `Σ_i x_i = 0` then, with
`s = Σ_{i∈S} x_i`,

```
xᵀ δ_S x = 2 ( Σ_{i∈S} x_i )( Σ_{j∉S} x_j ) = 2 s (−s) = −2 s² ≤ 0 .
```

Negative type is preserved by non-negative combinations, so `CUT_n ⊆ NEG_n`.

*Every metric on at most four points is ℓ₁-embeddable*, i.e. `MET_4 = CUT_4`
(Deza–Laurent, §6; the four-point metric cone is generated by its seven cut
semimetrics). Combining, `MET_4 = CUT_4 ⊆ NEG_4`: **no four-point subset of any
metric space whatsoever can violate negative type.** Five is therefore the
smallest conceivable size, for our metric or any other.

Numerical confirmation on our metric: 448,674 random 4-subsets of a
2,000-signature core gave `max_x xᵀDx = −8.47·10⁻⁴ < 0` at worst, and all five
4-subsets of the certificate below are of negative type (values `−3.0·10⁻³` to
`−2.0·10⁻²`).

### 2.4 A census, and a persistent shape

`five_point_census.py` collects distinct violating five-point families
(`five_point_violations.csv`). Seven were found, with defects from
`+1.06·10⁻⁴` to `+9.81·10⁻⁴`, and **all seven have exactly the same coarse
shape**:

* every signature has length 6 — the maximum the pool allows;
* the five largest fibres are always `{11, 11, 12, 12, 12}` — two signatures at
  one `log max` level and three at another.

The second point is not the same partition as the ±-split of the witness (for
the headline family the positive part is one max-11 and one max-12 signature),
but it is striking that the two-level structure of the `β = ∞` endpoint is
universal in the census: at `β = ∞` the rate between two signatures with equal
largest fibre is exactly 1 in both directions, so a two-level family has a
prescribed pattern of vanishing endpoint contributions.

Both features sit *at the pool boundary* (largest allowed length, largest
allowed entries), which is a warning: the pool is probably the binding
constraint on the margin, not the geometry. A sampled richer pool (15,000
signatures, length 5–9, entries ≤ 24) did not beat it, but only under a
low-yield protocol (0 of 60 seeded ascents; the same protocol also returns 0 of
60 on the pool that does contain violations), so that says nothing either way.

## 3. Why this family works: a K₂,₃ in the sup-norm picture

Split the five points by the sign of the witness:

```
P = { a₁, a₄, a₅ }   (x > 0)        N = { a₂, a₃ }   (x < 0)
```

| | distances |
| --- | --- |
| inside `P` | 0.030206, 0.059171, 0.061960 |
| inside `N` | 0.058307 |
| across `P`–`N` (6 pairs) | 0.040039, 0.022570, 0.036128, 0.026751, 0.026788, 0.036650 |

Mean inside a part `0.052411`, mean across `0.031488`, **ratio 1.66**. This is
the K₂,₃ pattern: the complete bipartite graph `K_{2,3}` has internal distance 2
and cross distance 1 (ratio 2, the extreme allowed by the triangle inequality),
and it is the classical smallest metric space failing negative type
(`xᵀ D x = +0.4` there). Our five signatures are a "soft" `K_{2,3}`: each point
of one part is nearly metrically *between* the points of the other part, which is
exactly what makes the cross distances small compared with the internal ones.

In the Chebyshev picture this says: the profiles `u_{a₂}, u_{a₃}` and
`u_{a₁}, u_{a₄}, u_{a₅}` are arranged so that each `P`–`N` difference
`u_p − u_n` oscillates over a *shorter* range than the differences inside either
group — the maxima and minima of the within-group differences are attained at
*different* β (one near `β ≈ 0`, another at `β = ∞`, others in between), so the
within-group oscillations add up while the cross ones partly cancel. Near-tight
triangle inequalities are the signature of this: two profiles whose difference
attains its max and min at the same β as a third pair make the triangle exact.
(T1.2 computes the exact positivity threshold for the graph metric of
`K_{m,n}`: `exp(−t·d) ⪰ 0 ⟺ t ≥ ½ log((m−1)(n−1))`, which for `K_{2,3}` is
`t* = ½ log 2 ≈ 0.347 > 0` — precisely the statement that `K_{2,3}` is not of
negative type. Our five signatures are a soft version of the same obstruction.)

In the pentagonal witness of §4 one such triple is exactly tight:

```
d( (10,6), (8,8,1,1,1,1) ) = d( (10,6), (9,9,2) ) + d( (9,9,2), (8,8,1,1,1,1) )
1.0516440785            = 0.5073981853       + 0.5442458933
```

so `(9,9,2)` is exactly metrically between the other two — the exchange metric has
genuine geodesic betweenness, and violations live on those flat faces.

Consistently with the K₂,₃ reading, the ±1 rounding of the witness,
`b = sign(x) = (1,−1,−1,1,1)`, already violates the **pentagonal** inequality on
the same five signatures: `Σ_{i<j} b_i b_j d_ij = +2.0719·10⁻²`. Negative type
fails here only because a hypermetric inequality fails first, and by a much
wider relative margin.

## 4. Which inequality fails first: the pentagonal one

Testing the small hypermetric inequalities `Σ_{i<j} b_i b_j d_ij ≤ 0` over a
2,000-signature core, maximizing each by a coordinate ascent that is *exact in
each coordinate* (with `b` fixed the form is linear in the row of `D` belonging
to any one point, so the best replacement is a single argmax over the core):

| inequality | b | status | best value (exact solver) |
| --- | --- | --- | --- |
| triangle | (1,1,−1) | **holds** (theorem) | `+2.2·10⁻¹⁶` (i.e. 0) |
| 4-point | (1,1,1,−2) | holds | `−3.51·10⁻⁴` |
| 4-point | (2,1,−1,−1) | holds | `−2.42·10⁻³` |
| **pentagonal** | **(1,1,1,−1,−1)** | **VIOLATED** | **`+5.393301020·10⁻²`** |
| 5-point | (2,1,1,−1,−2) | VIOLATED | `+9.65·10⁻³` |
| 5-point | (1,1,1,1,−3) | holds | `−9.20·10⁻³` |
| 6-point | (2,1,1,−1,−1,−1) | VIOLATED | `+4.19·10⁻²` |
| 6-point | (1,1,1,1,−1,−2) | VIOLATED | `+6.14·10⁻²` |
| 7-point | (1,1,1,1,−1,−1,−1) | VIOLATED | `+9.77·10⁻²` |
| 9-point | (1⁵,(−1)⁴) | VIOLATED | `+1.39·10⁻¹` |

**The pentagonal inequality is the smallest hypermetric inequality the exchange
metric violates, and nothing smaller can fail:** the triangle inequality is a
theorem of this project (equivalently, supermultiplicativity of the rates), and
every hypermetric inequality on ≤ 4 points is implied by the triangle
inequalities because `MET_4 = HYP_4 = CUT_4`. So the metric leaves the
hypermetric cone at exactly `n = 5`.

## 5. ℓ₁-embeddability

* On ≤ 4 points the exchange metric is always ℓ₁-embeddable, because *every*
  metric on ≤ 4 points is (`MET_4 = CUT_4`). Nothing to check.
* On 5 points it is not: `CUT_5` is cut out exactly by the triangle and
  pentagonal inequalities (Deza–Laurent; `HYP_5 = CUT_5`), and §4 exhibits a
  five-signature family violating the pentagonal one by `5.4·10⁻²`. So
  ℓ₁-embeddability breaks at exactly `n = 5` too.
* Consequently the metric is not `ℓ₁`, not hypermetric, and not of negative type;
  by Schoenberg, `√d` admits no Hilbert-space embedding and `exp(−t d)` fails to
  be PSD for small `t` on the five-point family of §2.2.

Note that ℓ₁ and negative type break at the same size, 5, but with very
different frequencies: pentagonal violations are easy to find and have relative
margins of order 0.3 of the mean distance, whereas negative-type violations are
rare and have relative margins of order 10⁻².

## 6. What was searched

Pool: all decreasing tuples of length 2…6 with entries in 1…12 and largest entry
≥ 2, deduplicated by the relation `d = 0` (which is genuine: `log Z_{a⊗k} = k log Z_a`,
so a signature and its tensor powers are the same point of the metric space) —
**18,537 distinct points**. Distances during search come from a 4,002-point
β-grid, accurate to `2·10⁻⁷` and always an *under*estimate; everything reported
was recomputed exactly.

| search | extent | outcome |
| --- | --- | --- |
| exhaustive sweep of all 5-subsets of a random 60-signature core | 5,461,512 subsets | **0 violations** |
| Monte Carlo over random k-subsets of a 2,000 core, k = 4,5,6,7 | ~450,000 each | **0 violations**; best defect `−8.47·10⁻⁴` in every k |
| greedy reduction (eigenvector shrink + one-at-a-time drop) from random 350–400 cores | 50 rounds | inclusion-minimal sizes `{6:1, 7:10, 8:20, 9:8, 10:7, 11:2, 13:1, 15:1}` |
| simulated annealing on the raw defect, k = 5,6,7,8 | 12 restarts × 80,000 steps, several cores | no violation; collapses onto small-diameter families (the objective is homogeneous — a dead end) |
| **alternating ascent over family and witness, whole pool, k = 5** | 408 runs | **22 reached a violation**; best `+9.8127·10⁻⁴` |
| — of those, starts seeded by 5-subsets of a known violating 6-point family | ~110 | 21 successes |
| — of those, purely random starts (incl. a 125-run census and a 60-run seeded-from-fresh-reductions hunt) | ~300 | 1 success |
| alternating ascent, k = 6,7 on cached cores | 150 restarts each | violations routinely; best `+4.03·10⁻³` |
| restricted pools, same protocols | 120 random + 60 seeded runs each | no violation found — see §7 |
| hypermetric coordinate ascent, 11 patterns of `b` | 200 restarts each | table in §4 |
| triangle inequality over a 2,000-signature core | all `8·10⁹` triples | minimum slack `−4.4·10⁻¹⁶` (i.e. 0 to roundoff) — holds |

Five-point violations are **rare**: no random 5-subset out of ~450,000, and none
of the 5,461,512 subsets of a 60-point core, comes close; roughly 1 in 300
random ascent starts converges to one, while ascents seeded from a 5-subset of
an already-violating six-point family succeed about one time in five. They must
be constructed, not stumbled upon — which is presumably why the earlier search
stopped at thirteen signatures.

The decisive methodological point: the negative-type defect is
`max{ xᵀ D_F x : Σx = 0, |x| = 1 }`, and one should optimize over the family
**and** the witness simultaneously. With `x` fixed the objective is linear in the
row of `D` belonging to any single point, so each coordinate can be updated by a
single argmax over the entire pool; with `F` fixed the best `x` is the top
eigenvector of `Q D Q^T` in an orthonormal basis `Q` of `{Σx = 0}`. Alternating
these two exact steps is what found five points; annealing, greedy reduction
from large violating cores, and exhaustive sweeps of small cores all failed to.
(A related trap: `−½ J D J` always has the constant vector in its kernel, so its
smallest eigenvalue is capped at 0 and carries no gradient — one must work in the
centred subspace. An early version of this search reported "no violation" for
every 5-subset for exactly that reason.)

## 7. Honest limits

* **Proved:** 4 points can never violate negative type (§2.1); the triangle
  inequality holds (project theorem); hence the pentagonal inequality is the
  smallest hypermetric inequality that *could* fail, and it does (§4).
* **Exhibited and verified to 40 digits:** a 5-point negative-type violation and
  a 5-point pentagonal violation. Since 4 is impossible, **the minimum is exactly
  5** — this part is now closed, not merely a search record.
* **Only searched, not settled:** how *small* the signatures may be. In the
  restricted pool of length ≤ 4 with entries ≤ 8 (486 points), 200 ascent runs
  found no 5-point violation, the best defect being `−3.89·10⁻³`; see the table
  below for the other restricted pools. That is evidence that violations need
  reasonably rich signatures, not a proof that small ones cannot work.
* **Only searched:** the maximal attainable margin. `+9.8·10⁻⁴` is the best
  5-point defect found; nothing here bounds the supremum.

| restricted pool | size | best 5-point defect found | violation? |
| --- | --- | --- | --- |
| length ≤ 4, entries ≤ 8 | 486 | `−3.888·10⁻³` | no |
| length ≤ 4, entries ≤ 12 | 1,797 | `−1.151·10⁻³` | no |
| length ≤ 5, entries ≤ 12 | 6,163 | `−6.105·10⁻⁴` | no |
| length ≤ 6, entries ≤ 8 | 2,984 | `−9.953·10⁻⁴` | no |
| length ≤ 6, entries ≤ 10 | 7,983 | `−3.287·10⁻⁴` | no |
| length ≤ 6, entries ≤ 12 | 18,537 | `+9.8127·10⁻⁴` | **yes** |

Each restricted pool got 120 random ascent starts plus 60 starts seeded from
inclusion-minimal violating families found inside that same pool. The trend
(the best defect creeping towards 0 as the pool grows) is suggestive but the
evidence is weak: the *same* seeded protocol, applied to the full pool with a
fresh seed, also returned 0 violations in 60 runs. Absence of a violation at
this budget is not evidence of absence.
